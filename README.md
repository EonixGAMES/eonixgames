# EONIX GAMES — دليل المالك

## فتح المشروع وتشغيل الموقع
1. افتح مجلد المشروع `EONIX_GAMES_PUBLIC_WEBSITE` في VS Code.
2. ثبّت إضافة Live Server إن لم تكن موجودة، ثم افتح `index.html` واختر **Open with Live Server**.
3. تعمل صفحات الموقع العام مباشرة كملفات ثابتة. تحتاج لوحة الإدارة إلى فتح الموقع عبر Live Server أو استضافة محلية، لأن المتصفح يمنع IndexedDB في بعض حالات `file://`.

## الدخول إلى لوحة الإدارة
افتح `admin/index.html`. بيانات الدخول الافتراضية في أول تشغيل هي اسم المستخدم `said` وكلمة المرور `said`، ثم ستُطلب كلمة مرور جديدة من 8 أحرف على الأقل. بيانات الدخول محفوظة محلياً في هذا المتصفح فقط، وليست مصادقة خادمية. إذا مُسحت بيانات المتصفح، تُعاد بيانات الدخول الافتراضية؛ النسخة الاحتياطية تحفظ المحتوى والوسائط لا كلمة المرور.

## الألعاب
من **Games** أضف لعبة أو حرّر مسودة موجودة. أدخل عنوانين ووصفين عند توفرهما، وslug لاتيني فريداً، وارفع الغلاف والبانر ولقطات الشاشة. اختر المنصة والحالة وأضف روابط المتاجر الفعلية فقط. استخدم Preview للمراجعة، ثم Save. لا تظهر اللعبة في التصدير العام حتى تفعّل Published. استخدم Edit وDuplicate وDelete لإدارة السجلات.

## المقالات والأخبار
من **Articles** أضف العنوان والslug والمقتطف والنص باللغتين، وصورة الغلاف والتاريخ والتصنيف عند توفرها. يبقى المقال مسودة إلى أن تفعّل Published. يعرض المحرر النص بأمان؛ النص العادي هو الخيار الأكثر توافقاً.

## Game Launch Hero
من **Game Launch** اختر لعبة منشورة، ارفع بانراً عريضاً، اضبط موضع التركيز، وأدخل العنوان والوصف ونص الزر اختيارياً. احفظ الإعدادات ثم أعد تصدير الموقع العام. إذا حُذفت اللعبة المحددة، يتوقف وضع الإطلاق عند التصدير.

## النسخ الاحتياطي والاستيراد
من **Backup & Export** اختر Export Admin Backup لحفظ بيانات اللوحة وكل الوسائط في ملف ZIP. للاستعادة اختر Import Admin Backup؛ افحص الملف أولاً ثم أكّد الاستبدال الواضح للبيانات الحالية. احتفظ بنسخة خارج المتصفح.

## تصدير ونشر الموقع العام
اختر **EXPORT PUBLIC WEBSITE ZIP**. الحزمة تحتوي صفحات الموقع العام والألعاب والمقالات المنشورة فقط، ولا تتضمن مجلد الإدارة أو المسودات أو بيانات الدخول. فك ضغط `EONIX_GAMES_PUBLIC_WEBSITE.zip` ثم ارفع محتوياته إلى مجلد الاستضافة العامة مع الحفاظ على هيكل الملفات. عند معرفة عنوان الموقع، أدخله قبل التصدير لتضمين sitemap وروابط SEO المطلقة.

تغييرات لوحة الإدارة محلية ولا تنتقل تلقائياً إلى الموقع المستضاف. صدّر ZIP جديداً وارفعه عند كل تحديث.
