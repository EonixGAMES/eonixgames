# EONIX GAMES — دليل المالك

المشروع يستخدم HTML وCSS وJavaScript عاديًا ويعمل على استضافة ثابتة دون Backend أو Build. افتح المجلد في VS Code وشغّل Live Server من index.html. لوحة الإدارة في admin/index.html؛ بيانات الدخول الأولى said / said ثم اختر كلمة مرور جديدة. الحماية محلية للمتصفح وليست حماية خادمية.

من Games أضف أو عدّل لعبة، أدخل بياناتها باللغتين، اختر المنصة والحالة، ارفع الصور، راجع Preview ثم احفظ وانشر. من Articles أضف الخبر أو المقال واحفظه كمسودة حتى يصبح جاهزًا للنشر. من Game Launch اختر لعبة منشورة وأضف بانرًا عريضًا واضبط موضع الصورة ثم احفظ.

من Backup & Export أنشئ نسخة Admin Backup لحفظ البيانات والوسائط. استعادة النسخة تستبدل البيانات الحالية بعد رسالة تأكيد. استخدم EXPORT PUBLIC WEBSITE ZIP لإنتاج حزمة الموقع العام المنشور. هذه الحزمة لا تحتوي admin أو المسودات أو بيانات الدخول. فك الضغط وارفع الملفات إلى استضافة ثابتة مع المحافظة على المجلدات. تغييرات لوحة الإدارة تبقى محلية ولا تصل للاستضافة تلقائيًا؛ صدّر وارفع نسخة جديدة بعد كل تعديل.
